# Верификация кодов

Для проверки кода сканированием можно воспользоваться обработкой **"Верификация кодов"**. Данная обработка расположена в подсистеме **"Честный знак"**:

[![1][1]][1]

Для работы необходимо указать номенклатуру, характеристику и партию. Далее отсканировать код или указать его в поле "Штрихкод". Полученный результат отобразится в таблице:

[![2][2]][2]

Если код правильно прочитался, а также соответствует указанным данным, то он будет окрашен зеленым цветом. В случае, если код пришел с ошибкой, информация об этом будет указана в всплывающем сообщении. Сам код будет окрашен в красный цвет.

По завершению верификации необходимо нажать кнопку **"Завершить сканирование"**. По результатам проверки будет создан документ **"Верификации кодов"**, который содержит в себе всю указанную информацию о проверяемой партии, корректные коды маркировок, а также информацию об ответственном за проверку:
